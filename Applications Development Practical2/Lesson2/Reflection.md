# Lesson 2 Reflection

## Topic

**Static Methods vs Non-Static (Instance) Methods**

# Reflection

This week I learned about the difference between **static methods** and **non-static (instance) methods** in Java. At first, I found it confusing to know when I needed to create an object and when I could call a method using the class name. After going through the examples and practising, I now understand that instance methods belong to objects, while static methods belong to the class.

I also learned how predefined classes such as `String`, `Scanner`, and `JOptionPane` use methods differently. The `String` and `Scanner` classes use instance methods because an object must be created first, while the `JOptionPane` class uses static methods that can be called directly using the class name.

Overall, this week's lesson helped me understand one of the most important concepts in Java. I know that understanding the difference between static and instance methods will help me write better Java programs in the future.

# Key Takeaways

- An instance method belongs to an object.
- A static method belongs to the class.
- Instance methods require an object before they can be called.
- Static methods can be called using the class name.
- `String` and `Scanner` mainly use instance methods.
- `JOptionPane` uses static methods.
- Understanding the difference between these methods is important when writing Java programs.
