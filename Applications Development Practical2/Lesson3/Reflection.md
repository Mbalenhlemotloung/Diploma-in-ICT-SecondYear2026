# Reflection

This week I learned about **ArrayLists** in Java and how they are different from normal arrays. Before this lesson, I only knew how to use arrays, but I learned that arrays have a fixed size and cannot grow or shrink once they have been created.

The lesson introduced me to the `ArrayList` class, which is part of the Java Collections Framework. I learned that an ArrayList can automatically grow when new elements are added and shrink when elements are removed. This makes it much more flexible than using a normal array.

I also learned how to declare an ArrayList, add elements, insert elements at a specific index, remove elements, and find the number of elements using the `size()` method. The examples in class helped me understand how the elements shift when an item is added or removed.

Overall, this lesson helped me understand why ArrayLists are commonly used in Java programs. I now know that they are useful when the number of items is unknown or may change while the program is running.

---

# Key Takeaways

- Arrays have a fixed size.
- ArrayLists can grow and shrink automatically.
- ArrayLists are part of the Java Collections Framework.
- ArrayLists are found in the `java.util` package.
- Only non-primitive data types can be stored in an ArrayList.
- The first element in an ArrayList has an index of **0**.
- The `add()` method is used to add elements.
- The `remove()` method is used to remove elements.
- The `size()` method returns the number of elements in the ArrayList.
- When an element is removed, the remaining elements shift to fill the empty space.
