## Key Takeaways

* A class serves as a blueprint for creating objects.
* Objects are instances of a class and represent real-world entities.
* Java has eight primitive data types, while `String` is a class and not a primitive type.
* Constructors are used to initialize objects when they are created.
* Getter and setter methods provide controlled access to an object's data.
* Method parameters allow information to be passed into methods.
* The `main()` method is the entry point of every Java application.
* The `Scanner` class is used to accept input from the user.
* Java is case-sensitive, meaning uppercase and lowercase letters are treated differently.
